# Musica Libre para tus Videos

Canciones de diferentes ritmos y estilos musicales, creadas especialmente para que las uses **gratis** como musica de fondo en tus videos.

---

## Escuchalas antes de descargar

Todas las canciones estan publicadas en Suno, donde puedes escucharlas completas antes de decidir cual usar:

**https://suno.com/@ruaj_electric**

Cuando encuentres la que te guste, vuelve aqui y descargala.

---

## Como descargar una cancion

**Paso 1.** Busca el archivo .mp3 en la lista de arriba y haz clic en el nombre.

**Paso 2.** Presiona el boton de descarga (Download raw file).

**Paso 3.** Listo, ya puedes usarla en tu video.

Tambien puedes descargar **todas** las canciones de una vez: boton verde **Code** (arriba a la derecha) y luego **Download ZIP**.
